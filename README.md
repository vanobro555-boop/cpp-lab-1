Сформировать умения, необходимые для создания классов и использования: переменных и констант, конструкторов, методов, перегрузки, логических блоков.

### 📂 Задания и реализация

#### Задание 1: Класс "Квадратное уравнение"
- **Условие:** Определить класс квадратного уравнения вида `ax² + bx + c = d`. Реализовать несколько конструкторов, методы для поиска корней, экстремумов и интервалов убывания/возрастания. Создать массив объектов и найти наибольшие/наименьшие корни.
- **Код:** [lab1task1OOP.cpp](./lab1task1OOP.cpp)
- **Ключевые особенности:**
  - Реализованы 3 конструктора: базовый, с параметрами, конструктор копирования
  - Метод `GetRoots` использует ссылочные параметры для возврата двух корней
  - Анализ дискриминанта для определения количества корней (0, 1 или 2)
  - Вычисление экстремумов через координаты вершины параболы `x0 = -b/(2a)`
  - Определение интервалов монотонности на основе направления ветвей параболы
  - Метод `CompareThreeEquations` работает с массивом из 3 объектов и находит глобальные максимум/минимум среди всех корней

#### Задание 2: Класс "Product" (Товар)
- **Условие:** Создать класс товара с атрибутами (id, name, UPC, manufacturer, price, shelf_life, count). Реализовать конструкторы, сеттеры, геттеры и метод `showInformation`. Создать массив объектов и реализовать поиск по критериям.
- **Код:** [lab1task2OOP.cpp](./lab1task2OOP.cpp)
- **Ключевые особенности:**
  - Динамическое выделение памяти под массив объектов через `new Product[size]`
  - Корректное освобождение памяти через `delete[] array`
  - Валидация пользовательского ввода (проверка на отрицательные цены, сроки хранения)
  - Три критерия поиска:
    1. По наименованию товара
    2. По наименованию с ограничением по цене
    3. По сроку хранения (больше заданного)
  - Использование `cin.ignore()` и `getline()` для корректной работы со строками

###  Что было изучено и реализовано:
- **Перегрузка конструкторов** — гибкая инициализация объектов в разных сценариях
- **Конструктор копирования** — глубокое копирование атрибутов объекта
- **Инкапсуляция** — все атрибуты класса приватные, доступ через геттеры и сеттеры
- **Работа с массивами объектов** — итерация, поиск, сравнение элементов
- **Динамическое управление памятью** — создание и удаление массивов через `new`/`delete`
- **Обработка пользовательского ввода** — валидация данных и защита от некорректного ввода
